# 🛏️ Bed Battle 3D — Version 1

A first-person, blocky "bed wars" style game that runs in your web browser. Protect your bed, break everyone else's, and be the last team standing!

## How to play
Open `index.html` in a web browser (Chrome works best). You need an internet connection the first time so it can load the 3D library.

| Key | What it does |
|---|---|
| WASD | Walk |
| Mouse | Look around (click the game first) |
| Space | Jump |
| Left click | Use what you're holding (sword, bow, fireball, TNT…) |
| Right click / Q | Build with wool |
| 1–9 / mouse wheel | Pick an item |
| E | Item shop / Upgrade shop (stand next to the villager) |
| R | Use your kit's super power |
| F | Eat a golden apple |
| P / K | Play menu / Kits (in the lobby) |
| Esc | Pause |

## What's in Version 1
- **Lobby** with a green PLAY portal, purple KITS portal and a big yellow AFK portal
- **Modes:** Doubles, Squads, 5v5 and 16v16 with smart bots
- **5 maps:** Desert Ruins, Frosty Peaks, Jungle Temple, Lava Volcano, Candy Land
- **56 kits** (6 free "bad" kits + 50 with powers, including Barbarian, whose sword upgrades with kills up to the 30-damage Rageblade)
- **Bed Coins:** 1,000 every 2 days; buy a kit for 10,000 or rent one for 1,500 (3 days)
- **Item shop:** swords up to Emerald, armor up to Emerald, Bow (7), Crossbow (20), Headhunter (33), pickaxe, golden apples, speed potions, fireballs, TNT, ender pearls
- **Team upgrades** paid with diamonds: Sharpened Swords, Reinforced Armor, Iron Forge, Maniac Miner, Heal Pool, Bed Armor
- **Generators:** iron & gold at every base, 4 diamond generators, emeralds every 30 seconds
- Build **up to 150 blocks high** and bridge out across a huge map
- 100 health, critical hits from jumping, damage numbers, Sudden Death at 8:00
- Graphics: Fast / Fancy / Ultra, Max FPS: 60 / 100 / 144 / Max

## Notes
- Bed Coins and kits are saved in your browser when you play this file directly. (The Claude-hosted version saves them to your account.)
